# Stellar website starter

A responsive one-page website inspired by the supplied Stellar branding concept. Built with plain HTML, CSS, and JavaScript for easy editing and GitHub Pages hosting.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, responsive styles, color palette, effects
- `script.js` — mobile navigation, current year, demo interest form
- `assets/` — generated cosmic and genre artwork

## Run locally
Open `index.html` in your browser. For a more realistic local server, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `stellar-website`).
2. Upload all files and the `assets` folder, preserving the folder structure.
3. Open **Settings → Pages** in the repository.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to provide the published URL.

## Before launch
- Replace `stellar@example.com` in `script.js` with your actual public inbox, or connect a form service such as Formspree/Netlify Forms. The current form opens the visitor's email application; it does not store applications on a server.
- Replace placeholder social links with your real Discord and social profiles when ready.
- Update program descriptions and certification language to match what you are actually offering.
- Check image permissions and any third-party logos before publishing. The artwork included here was generated for this concept and is not official game artwork.
- Add a privacy policy if you collect personal information.
